# Правила сервера (Nakama, TypeScript)

Сервер — единственный источник правды по валютам, предметам и прогрессу. Клиенту не доверяем ни одно число.

- Любое изменение кошелька и инвентаря — через `src/economy/ledger.ts`: одна транзакция, запись в журнал (`user_id`, причина, было/стало, источник), идемпотентный ключ операции.
- Каждый RPC: проверить сессию → валидировать вход схемой → проверить лимиты (серверное время, дневные счётчики) → выполнить → вернуть новое состояние. Ошибки — `RpcError` с кодом из `src/errors.ts`.
- Награда за забег начисляется только после проверки журнала в `validator/` и совпадения результата.
- Покупки: только RuStore Pay. Статус платежа проверяется через API RuStore, товар выдаётся один раз (ключ — id покупки), возврат отзывает товар. Из сборки `gplay` RPC покупки отвечают ошибкой `PAYMENTS_DISABLED`.
- Цены, товары и лимит трат на аккаунт в месяц — в удалённом конфиге (лимит выключен, но готов к включению по закону).
- Награды за рекламу: только по серверному подтверждению Яндекс Рекламной сети с проверкой подписи; RPC «посмотрел рекламу» с клиента наград не даёт. Дневной лимит роликов считает сервер.
- Время — только серверное. Граница суток для сбросов — 00:00 МСК (UTC+3); в базе время храним в UTC.
- Персональные данные граждан РФ хранятся только на серверах в России (152-ФЗ); никаких зарубежных SaaS для данных игроков.
- Изменение формата хранилища — новая версия схемы и миграция данных, старые записи не ломаем.
- На каждый RPC — тесты в `server/tests/`: успешный путь, повтор с тем же ключом, превышение лимита, подделанные данные.
- Персональные данные (почта, id соцсетей) — минимум, без логирования в открытом виде.
