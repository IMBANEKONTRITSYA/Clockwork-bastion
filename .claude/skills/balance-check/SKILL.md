# Balance check

1. `make data`, затем `make sim RUNS=${ARGUMENTS:-10000}`.
2. Возьми последний и предыдущий отчёты из `tools/out/` и сведи в таблицу «было → стало»: волна смерти (медиана, p10, p90), прохождение глав 1 и 2, урон по типам шестерней, частота выбора чертежей, Латунь за забег.
3. Отметь нарушения целей из `.claude/rules/data-balance.md`.
4. Если нарушений нет — коротко «баланс в норме». Если есть — передай отчёт субагенту `balance-analyst` за предложениями.
