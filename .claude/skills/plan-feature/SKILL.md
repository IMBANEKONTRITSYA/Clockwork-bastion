# Plan feature

Задача: $ARGUMENTS

1. Прочитай CLAUDE.md, `docs/design/mvp-scope.md`, `docs/design/core-rules.md` и нужный раздел `docs/plan/game-plan.md` (найди его через grep по заголовкам `## `).
2. Если фича вне MVP — скажи об этом и спроси, делать ли.
3. Для крупной задачи вызови субагента `architect`.
4. Создай `docs/plans/NN-<кратко>.md` (NN — следующий номер) по шаблону:
   ```
   # NN. <Название>
   Цель: <одно предложение — что увидит игрок>
   Раздел плана: <ссылка на заголовок в game-plan.md>

   ## Шаги
   - [ ] 1. <шаг> — тест: <какой тест подтверждает>
   - [ ] 2. ...

   ## Затрагиваемые файлы
   ## Риски (детерминизм, сервер, производительность)
   ## Обучение игрока (если новая механика)
   ## Готово, когда
   ```
5. Каждый шаг — один коммит, проект после него собирается и тесты проходят.
6. Покажи план пользователю и дождись «ок» перед кодом.
