# Правила механик для реализации (MVP)

Источник истины для кода `client/sim/` и `validator/`. Числа здесь — стартовые; рабочие значения живут в `data/balance/*.csv`. Если правило и CSV расходятся — прав CSV, а этот файл нужно обновить.

## 1. Время и числа
- Симуляция идёт тиками: **30 тиков в секунду**. Секунды в правилах ниже переводятся в тики (`1 с = 30 тиков`).
- Только целые числа. Дробные величины — фиксированная точка **×1000** (`1.0 = 1000`, `0.8 = 800`). Умножение: `a * b / 1000` с целочисленным делением.
- Степени (0.8ⁿ, 2.4ⁿ, 1.13ⁿ) — заранее посчитанные таблицы, не `pow()`.
- Случайность — только `SimRng` (xorshift32 (сдвиги 13, 17, 5), посчитанный на 64-битных int с маской `0xFFFFFFFF`) с зерном от сервера. Порядок вызовов RNG — часть протокола: менять его = ломать проверку старых забегов.

## 2. Порядок одного тика
1. Применить входы игрока этого тика из журнала (поставить, переставить, слить, Реверс, выбить клин, выбрать чертёж).
2. Если сетка изменилась — пересчитать привод (раздел 3).
3. Шестерни продвигают фазу и атакуют (раздел 4).
4. Снаряды и эффекты.
5. Монстры двигаются, бросают клинья, бьют Стену.
6. Урон, смерти, выпадение гаек.
7. Директор волн: спавн, конец волны, пауза.

## 3. Сетка и привод
- Сетка 7 колонок × 5 рядов, координаты `(x, y)`, `x = 0..6`, `y = 0..4`, `y = 4` — нижний ряд. Сердце — `(3, 4)`.
- Шестерни сцепляются по 4 сторонам. Подключена = есть путь соседей до Сердца (обход в ширину). Неподключённые не крутятся.
- Направление: Сердце ↻. Подключённая шестерня ↻, если `(x + y) % 2 == (3 + 4) % 2`, иначе ↺. После Реверса всё наоборот.
- Цепь (спецдеталь) соединяет две шестерни через одну пустую клетку и передаёт вращение БЕЗ смены направления. Если направления по шахматке противоречат цепи — обе шестерни заклинены.
- Мощность: `P` (старт 8), нагрузка `L` = число подключённых шестерней (мультипликатор ×2 нагрузки ниже себя). Коэффициент `k = min(1000, P * 1000 / L)`.
- Скорость: `rpm = 60 * k/1000 * size(t) * (1000 + bonus)/1000`, где `size = [1000, 800, 640, 512, 410]` для уровней 1–5.
- Раскрутка после начала волны и после Реверса — линейно за 60 тиков (2 с).

## 4. Шестерни и атаки
- Урон за удар: `base * dmgMul(t)`, `dmgMul = [1000, 2400, 5760, 13824, 33178]`.
- Атаки срабатывают по фазе: `ударов за оборот` из таблицы типа; фаза копится от rpm каждый тик.
- Режим ↻ «Натиск», режим ↺ «Отдача» — у каждого типа свой эффект (`data/balance/gears.csv`).
- Мерж: две шестерни одного типа и уровня → уровень +1 (макс. 5).

## 5. Реверс, клинья, конвейер
- Реверс: тап по Сердцу. Механизм стоит 45 тиков (1,5 с), затем раскрутка; перезарядка 600 тиков (20 с).
- Клин: шестерня заклинена 180 тиков (6 с) или до 3 тапов; всё, что питалось только через неё, тоже стоит.
- Конвейер: новая шестерня каждые 150 тиков (5 с), 3 слота; при переполнении крайняя уходит в переплавку (+1 гайка).

## 6. Монстры и волны
- HP: `HP0 * hpMul(w)`, `hpMul` — таблица 1.13^(w−1) в ×1000. Глава 2 — ещё ×1600/1000.
- Бюджет волны: `10 + 4w` очков, стоимость монстров — в `data/balance/monsters.csv`.
- Стена: 100 прочности. Проигрыш, когда прочность ≤ 0.

## 7. Герои в бою
- 4 места: Сердце (считает атаки всего механизма), левый пост (колонки 0–1), правый пост (колонки 5–6), верхний пост (ряды 0–1).
- Герой даёт +15% урона шестерням своей стихии в своей зоне. Резонанс: 2/3/4 героя одной стихии — +5/+12/+20%.
- Все навыки героев пассивные: счётчик атак, шанс (через `SimRng`), событие (Реверс, мерж, начало волны, убийство элиты), порог (Стена < 30%, раз за волну).
- Стихии: Пламя → Иней → Гроза → Патина → Пламя (стрелка = сильнее): +25% / −15%. Сталь нейтральна.
- Скины: бонус надетого скина (+3…+6% к одному параметру и 0…+3% ко второму, таблица `data/balance/skins.csv`) и бонус коллекции (+0,5% Прочности за скин, максимум +5%) применяются к параметрам героя ОДИН раз при создании состояния забега: `param = param * (1000 + bonus_permille) / 1000`. Внутри боя скины не участвуют. Бонусы входят в мета-состояние и `loadout_hash`. В режимах «Уравнитель» и спарринг бонусы скинов = 0.

## 8. Журнал забега (протокол клиент ↔ сервер)
```json
{ "run_id": "uuid", "seed": 123456789, "chapter": 1, "squad": ["frol", "ida", "kholodok", "klyopa"],
  "loadout_hash": "sha256 мета-состояния на начало забега",
  "inputs": [[120, "place", {"slot": 0, "x": 3, "y": 3}], [400, "reverse", {}]],
  "client_result": { "waves": 12, "wall": 34, "kills": 210 } }
```
Сервер пересчитывает забег; если результат не совпал с `client_result` — награда не начисляется, забег помечается для проверки.
