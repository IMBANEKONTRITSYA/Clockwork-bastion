# 07. Проверка забегов
Цель: награда за забег начисляется только после того, как сервер пересчитал журнал тем же кодом `client/sim/` и результат совпал.
Раздел плана: «Сервер и аккаунты: всё ценное хранится на сервере»; `core-rules.md`, раздел 8; ADR-002.

## Шаги
- [ ] 1. RPC `run_start`: сервер выдаёт `run_id` и зерно, запоминает `loadout_hash`, главу и `SIM_VERSION` — тест: `run_start.test.ts`
- [ ] 2. `validator/`: headless-экспорт Godot, читает журнал из stdin, печатает результат и хэш состояния; использует `client/sim/` без копий — тест: `make determinism` сравнивает клиент и валидатор
- [ ] 3. Воркер рядом с Nakama: очередь забегов, таймаут, ограничение CPU и памяти — тест: интеграционный тест в docker compose
- [ ] 4. RPC `run_submit`: свой `run_id`, только один раз, совпадение версии и `loadout_hash`, предел длины журнала; при несовпадении результата забег помечается для проверки, награды нет — тест: `run_submit.test.ts` (честный принят, подделанный и повторный отвергнуты)
- [ ] 5. Награды за забег (Латунь за волны и боссов даже при поражении, осколки, гайки не переносятся) — числа из конфига, через журнал экономики — тест: `rewards.test.ts`
- [ ] 6. Клиент: забег доигрывается без связи, журнал ставится в очередь и уходит позже; на экране итогов статус «проверяется» — тест: GUT с заглушкой сети
- [ ] 7. Правило версий `SIM_VERSION` и ADR-004 «Версионирование симуляции» — тест: забег старой версии обрабатывается по правилу
- [ ] 8. Регрессионный набор поддельных журналов `client/tests/fixtures/runs/tampered/` — тест: все отвергнуты

## Затрагиваемые файлы
`validator/**`, `server/src/rpc/run_*.ts`, `server/src/validation/*`, `server/tests/*`, `client/services/run_submit.gd`, `docs/decisions/ADR-004-sim-versioning.md`

## Риски (детерминизм, сервер, производительность)
- Нагрузка: забег на 20 волн ≈ 36 000 тиков — замерить время валидации, цель < 2 с на забег.
- Любое расхождение клиента и валидатора — блокер релиза.

## Обучение игрока
Нет.

## Готово, когда
Честные забеги принимаются, подделанные отвергаются, награда приходит после проверки; `make determinism` зелёный в CI.
