# 02. Серый прототип боя
Цель: на телефоне можно сыграть 10 волн серыми фигурами: ставить, сливать, реверсировать.
Раздел плана: «Ключевые механики», «Визуальный стиль и интерфейс», «Недели 1–2 — серый прототип».

## Шаги
- [ ] 1. `game/battle_scene.tscn` + `battle_controller.gd`: каждый кадр шагает sim с фиксированным шагом 30 тиков/с (аккумулятор), входы игрока пишутся в журнал — тест: `tests/game/test_battle_controller.gd` (300 тиков без ошибок)
- [ ] 2. Отрисовка поля: монстры, снаряды, Стена с полосой прочности; интерполяция между тиками только в `game/` — тест: smoke-тест сцены
- [ ] 3. Сетка: клетки, шестерни с поворотом и стрелкой направления, серые неподключённые, подсветка ↻ (янтарь) / ↺ (бирюза) до установки — тест: `test_grid_view.gd` (цвет клетки = направление из sim)
- [ ] 4. Ввод: перетаскивание с конвейера на сетку, перестановка, на такую же шестерню — мерж; жест превращается во вход журнала — тест: `test_input_to_log.gd`
- [ ] 5. HUD: тап по Сердцу = Реверс (кольцо перезарядки), манометр нагрузки P/L, гайки, номер волны, конвейер на 3 слота — тест: `test_hud.gd` на моковом состоянии
- [ ] 6. Пауза между волнами (15 с, кнопка «Дальше»), экраны поражения и победы, скорость ×2 — тест: `test_battle_flow.gd`
- [ ] 7. Пул снарядов и эффектов без выделения памяти во время волны — тест: `test_pool.gd`
- [ ] 8. Локализация: все строки через `tr()`, `client/i18n/strings.csv` (ru, en) — тест: `test_i18n.gd` (нет ключей без перевода)
- [ ] 9. Пресет экспорта Android debug (без ключей пользователя), инструкция установки на телефон в README — тест: debug-APK собирается в CI
- [ ] 10. **Проверка 1:** чек-лист плейтеста (5 человек × 3 забега подряд без подсказок) и вопросы в `docs/playtests/01.md` — тест: решение пользователя «цепляет / меняем ядро»

## Затрагиваемые файлы
`client/game/**`, `client/i18n/strings.csv`, `client/export_presets.cfg`, `client/tests/game/*`, `.github/workflows/ci.yml`

## Риски (детерминизм, сервер, производительность)
- `game/` только читает состояние sim и шлёт входы — никакой логики боя в сценах.
- Скорость ×2 = 2 шага sim за кадр, а не другой шаг.

## Обучение игрока
Только точки входа для обучения (постановка, мерж, направление, Реверс); сами обучения — этап 08.

## Готово, когда
Debug-APK ставится на телефон, 10 волн играются, Проверка 1 пройдена.
