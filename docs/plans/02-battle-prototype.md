# 02. Серый прототип боя
Цель: на телефоне можно сыграть 10 волн серыми фигурами: ставить, сливать, реверсировать.
Раздел плана: «Ключевые механики», «Визуальный стиль и интерфейс», «Недели 1–2 — серый прототип».

## Шаги
- [x] 1. `game/battle_scene.tscn` + `battle_controller.gd`: каждый кадр шагает sim с фиксированным шагом 30 тиков/с (аккумулятор), входы игрока пишутся в журнал — тест: `tests/game/test_battle_controller.gd` (300 тиков без ошибок)
- [x] 2. Отрисовка поля: монстры, снаряды, Стена с полосой прочности; интерполяция между тиками только в `game/` — тест: smoke-тест сцены
- [x] 3. Сетка: клетки, шестерни с поворотом и стрелкой направления, серые неподключённые, подсветка ↻ (янтарь) / ↺ (бирюза) до установки — тест: `test_grid_view.gd` (цвет клетки = направление из sim)
- [x] 4. Ввод: перетаскивание с конвейера на сетку, перестановка, на такую же шестерню — мерж; жест превращается во вход журнала — тест: `test_input_to_log.gd`
- [x] 5. HUD: тап по Сердцу = Реверс (кольцо перезарядки), манометр нагрузки P/L, гайки, номер волны, конвейер на 3 слота — тест: `test_hud.gd` на моковом состоянии
- [x] 6. Пауза между волнами (15 с, кнопка «Дальше»), экраны поражения и победы, скорость ×2 — тест: `test_battle_flow.gd`
- [x] 7. Пул снарядов и эффектов без выделения памяти во время волны — тест: `test_pool.gd`
- [x] 8. Локализация: все строки через `tr()`, `client/i18n/strings.csv` (ru, en) — тест: `test_i18n.gd` (нет ключей без перевода)
- [x] 9. Пресет экспорта Android debug (без ключей пользователя), инструкция установки на телефон в README — тест: debug-APK собирается в CI
- [x] 11. Правки по первой игре: сетка 5×4, покупка 1–3 шестерней за гайки вместо конвейера, раскладка под любую высоту экрана — тест: `test_stock_merge.gd`, `test_battle_layout.gd`, `make determinism`, отчёт `make sim`
- [x] 12. Интерфейс и волны по второй игре: шестерни с номером уровня, ворота, полоса босса, «В бой!» с автостартом, «Купить», пауза; волны ≤ 15 по `waves.csv`, боссы на 5 и 10 — тест: `test_waves.gd`, `test_battle_layout.gd`, `test_battle_hud_model.gd`, `make determinism`
- [ ] 10. **Проверка 1:** чек-лист плейтеста (5 человек × 3 забега подряд без подсказок) и вопросы в `docs/playtests/01-core-check.md` — тест: решение пользователя «цепляет / меняем ядро»

## Затрагиваемые файлы
`client/game/**`, `client/i18n/strings.csv`, `client/export_presets.cfg`, `client/tests/game/*`, `.github/workflows/ci.yml`

## Риски (детерминизм, сервер, производительность)
- `game/` только читает состояние sim и шлёт входы — никакой логики боя в сценах.
- Скорость ×2 = 2 шага sim за кадр, а не другой шаг.

## Обучение игрока
Только точки входа для обучения (постановка, мерж, направление, Реверс); сами обучения — этап 08.

## Готово, когда
Debug-APK ставится на телефон, 10 волн играются, Проверка 1 пройдена.

## Правки по первой игре (19.11.2026, шаг 11)
- Отзыв: сетка велика, шестерни приходят слишком часто (не успеваешь сливать), внизу экрана пусто, нужна валюта для покупки шестерней.
- Сделано: сетка 5×4 (Сердце (2, 3)); конвейер убран — вход `buy` даёт 1–3 случайные шестерни за гайки (цена 8, +4 за покупку), запас на 4 слота; раскладка подстраивается под высоту экрана (stretch `keep_width`). `SIM_VERSION` = 2, новый эталон `bot-101` (`f7d6bd06`).
- Баланс (`make sim`, 100 забегов на вариант цены): 6/+2 → 15 покупок, 8/+4 → 11 (выбрано, ~1 покупка за волну), 10/+6 → 9, 12/+8 → 7. Бот выигрывает 100% при любой цене, Стена в среднем 89–97 — сложность задаётся волнами и здоровьем монстров, это этап 04.
- `make sim VARIANTS="k=v|k=v"` перебирает наборы параметров `run.csv` за один прогон.
- Осталось: повторная игра на телефоне (шаг 10).

## Интерфейс, волны и боссы по второй игре (20.11.2026, шаг 12)
- Отзыв: интерфейс как у merge-TD со скриншотов, но в нашем стиле; боссы на волнах 5 и 10; не больше 15 монстров на волну, рост сложности плавный.
- Сделано: `waves.csv` (8→15 монстров, здоровье +~10% за волну), Ржавый Колосс и Магнитрон (пока без способностей — этап 03); интерфейс: зубчатые шестерни с крупным номером уровня и стрелкой, латунные ворота, полоса босса, верхняя панель, круглые «пауза» и «×2», «В бой!» с автостартом и предупреждением о боссе, широкая «Купить». `SIM_VERSION` = 3.
- Баланс (`make sim`, 60 забегов на вариант `monster_hp_scale`): ×1 → Стена 96/70 (среднее/минимум), ×2,2 → 78/35, ×2,8 → 78/20 (выбрано, забег ~6,7 мин), ×3,5 → 75/20. Бот выигрывает при любом множителе — угрозу добавят Клинщик, Масложор и способности боссов (этап 03).
