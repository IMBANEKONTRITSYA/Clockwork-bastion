# 10. Монетизация и аналитика
Цель: ролики за бонусы и покупки RuStore Pay работают и проверяются сервером; в сборке `gplay` оплаты нет; аналитика и падения собираются.
Раздел плана: «Монетизация: принципы и реклама», «Магазин: карты, наборы и копилка» (только MVP-товары), «Неделя 8»; ADR-003.

## Шаги
- [ ] 1. `client/services/store.gd`: `Store.current()` и `Store.has_payments()` по флагу сборки; пресеты экспорта «Android RuStore» и «Android Google Play» — тест: в `gplay` магазин за деньги недоступен + проверка сборки на отсутствие цен в ₽
- [ ] 2. Android-плагин Yandex Mobile Ads (только rewarded) + `services/ads.gd` с заглушкой для ПК — тест: GUT на заглушке
- [ ] 3. Сервер: подтверждение награды от Яндекс Рекламной сети (проверка подписи, идемпотентность, дневные лимиты из конфига) — тест: `ads_reward.test.ts`
- [ ] 4. Все точки бонусов «за ролик» из таблицы game-plan с лимитами — тест: тест на каждую точку
- [ ] 5. Плагин RuStore Pay SDK + `services/shop.gd` (только за `Store.has_payments()`) — тест: GUT на заглушке
- [ ] 6. Сервер: проверка платежа через API RuStore, выдача ровно один раз, обработка возвратов, восстановление покупок — тест: `purchase.test.ts` (повтор, поддельный чек, возврат)
- [ ] 7. Каталог: алмазы (6 наборов, ×2 при первой покупке), стартовый набор (300 алмазов, осколки и скин Иды), «Тишина цеха» (бонусы без роликов) — тест: `catalog.test.ts`
- [ ] 8. Упрощённый пропуск на 30 уровней: бесплатная и платная ветки, эпический скин Холодка; скин Фрола — за 10★ — тест: `pass.test.ts`
- [ ] 9. Аналитика: воронка обучения, смерти по волнам, просмотры бонусов — в таблицу на сервере; падения — Sentry или GlitchTip (зависимость — с вашего согласия) — тест: тест отправки событий
- [ ] 10. Админка: история операций игрока, ручной возврат, пометка подозрительного аккаунта; RPC только для роли admin — тест: `admin.test.ts` (без роли — отказ)
- [ ] 11. Аудит субагентом `economy-auditor` — тест: нет критичных замечаний

## Затрагиваемые файлы
`client/services/{store,ads,shop,analytics}.gd`, `client/android/plugins/*`, `client/meta/shop/*`, `server/src/{rpc,economy}/*`, `data/balance/{shop,pass,ad_bonuses}.csv`

## Риски (детерминизм, сервер, производительность)
- Награды — только по серверному подтверждению; клиенту не доверяем.
- Никаких цен в ₽ и ссылок на оплату в сборке `gplay`.
- Не используем AdMob, Google UMP и Facebook SDK.

## Обучение игрока
Короткое знакомство с магазином и пропуском при первом открытии вкладки.

## Готово, когда
Покупки, возвраты и награды за рекламу проверены на тестовых аккаунтах; аудит без критичных замечаний.
