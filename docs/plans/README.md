# Планы реализации

Каждая крупная задача начинается с файла `NN-<кратко>.md` (skill `/plan-feature`). Claude видит самый свежий план при старте сессии (хук `session-context.sh`).

Правила:
- Шаги — чекбоксы `- [ ]`, у каждого шага свой тест.
- Отмечай `- [x]` по мере выполнения, не удаляй выполненное.
- Решение, которое меняет архитектуру, — отдельный ADR в `docs/decisions/`.

Порядок этапов MVP (по `docs/design/mvp-scope.md` и разделу «План по неделям» в `docs/plan/game-plan.md`). Всё вне MVP — рейтинги, арены, сундуки, месячные и вечные карты — сюда не входит.

## Что нужно от пользователя
- Godot 4.7.2 с шаблонами экспорта и Android SDK — с этапа 00; тестовый телефон — с этапа 02.
- ИП и расчётный счёт; аккаунты RuStore, Google Play, Яндекс Рекламной сети, VK ID, Яндекс ID — к этапам 06–10.
- VPS в России — к этапу 06; 15–20 тестеров — к этапу 09; ключи подписи — к релизу.
- Решения на Проверке 1, Проверке 2 и по стиль-гайду.

## Зависимости, которые понадобятся
Добавляются только с явного согласия в момент шага: GUT (этап 00), клиент Nakama для Godot (06), Yandex Mobile Ads SDK и RuStore Pay SDK (10), Sentry SDK (10).
