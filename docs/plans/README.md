# Планы реализации

Каждая крупная задача начинается с файла `NN-<кратко>.md` (skill `/plan-feature`). Claude видит самый свежий план при старте сессии (хук `session-context.sh`).

Правила:
- Шаги — чекбоксы `- [ ]`, у каждого шага свой тест.
- Отмечай `- [x]` по мере выполнения, не удаляй выполненное.
- Решение, которое меняет архитектуру, — отдельный ADR в `docs/decisions/`.

Порядок этапов MVP (по разделу «Недели 1–10» в `docs/plan/game-plan.md`):

| № | Этап | Недели |
|---|------|--------|
| 00 | Каркас репозитория, CI, пустой проект Godot, сервер в Docker | 1 |
| 01 | Симуляция: сетка, привод, шестерни, монстры, волны | 1–2 |
| 02 | Отображение боя, ввод, конвейер, мерж | 2–3 |
| 03 | Реверс, клинья, цепи, чертежи, боссы | 3–4 |
| 04 | Герои, посты, звёзды и навыки | 4–5 |
| 05 | Сервер: вход, кошелёк, ledger, валидатор забегов | 5–6 |
| 06 | Мета: мастерская, вещи, сундуки, обучение | 6–7 |
| 07 | Рейтинги, стихийные арены, спарринг, напарники | 7–8 |
| 08 | Монетизация: магазин, карты, rewarded, покупки | 8–9 |
| 09 | Полировка, аналитика, закрытый тест, публикация | 9–10 |
