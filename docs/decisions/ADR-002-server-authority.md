# ADR-002. Сервер — источник правды, забеги проверяются пересимуляцией

Статус: принято · Дата: 2026-11-17

## Контекст
Валюты, предметы, герои и рейтинги должны быть защищены от взлома клиента. Бой длится минуты и состоит из тысяч событий — передавать их все на сервер в реальном времени дорого.

## Решение
1. Все валюты, предметы, герои и прогресс хранятся только на сервере. Клиент показывает то, что вернул сервер.
2. Перед забегом сервер выдаёт `run_id` и `seed` и фиксирует хэш мета-состояния (герои, вещи, чертежи).
3. Бой — детерминированная симуляция: 30 тиков/с, целые числа ×1000, свой RNG (`SimRng`). Клиент пишет журнал действий `[tick, action, args]`.
4. После забега клиент отправляет журнал. `validator/` проигрывает его тем же кодом и сравнивает результат. Совпало — награда; нет — без награды, забег помечается.
5. Журнал проверяется асинхронно; для рейтингов — обязательно, для обычных наград — выборочно плюс всегда при аномалиях (резкий рост силы, рекорды).
6. Версия симуляции (`SIM_VERSION`) входит в журнал; сервер держит валидаторы для текущей и предыдущей версии.

## Последствия
- В `client/sim/` запрещены float, системное время и системная случайность (хук `determinism-guard.sh`).
- Офлайн-игры нет: без сети можно только смотреть меню.
- Копии игроков для спарринга и напарников — это сохранённые на сервере снимки состояния, а не живые клиенты.
