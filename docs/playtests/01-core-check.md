# Проверка 1: цепляет ли ядро

Когда: после этапа 02, на debug-APK. Кто решает: ты (финальное «да/нет»).
Цель: понять, хочется ли играть в механизм «шестерни от Сердца + Реверс» без арта, звука и меты. Если не цепляет — меняем ядро, а не добавляем контент.

## Подготовка
1. Скачай APK: GitHub → Actions → последний зелёный запуск CI → Artifacts → `clockwork-bastion-debug` (zip с APK внутри).
2. Установи на телефон (разреши установку из неизвестных источников). Игра работает без интернета.
3. 5 человек, которые не видели игру. Каждый играет **3 забега подряд**, ты молча смотришь.

## Что нельзя делать
- Объяснять правила до или во время игры (кроме «перетаскивай шестерни снизу на сетку»).
- Подсказывать, когда человек застрял. Записывай, где застрял.

## Что записать по каждому игроку
| Вопрос | Игрок 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |
| Понял сам, что шестерня крутится, только если касается Сердца/цепочки? (да / к какому забегу) | | | | | |
| Заметил два цвета (↻ янтарь / ↺ бирюза) и что режимы разные? | | | | | |
| Нажал Реверс сам? Сколько раз за забег? | | | | | |
| Сливал шестерни (мерж)? | | | | | |
| До какой волны дошёл в забегах 1 / 2 / 3 | | | | | |
| Захотел 4-й забег без просьбы? | | | | | |
| Одной фразой: что было скучно? | | | | | |
| Одной фразой: что понравилось? | | | | | |

## Решение
- **Цепляет**, если хотя бы 3 из 5: сами поняли привод к 2-му забегу, нажимали Реверс осознанно и захотели 4-й забег. → Идём в этап 03.
- **Не цепляет** — выписываем 3 главные причины и правим ядро (скорость боя, ясность направления, сила Реверса), повторяем проверку.

Известно заранее: баланс пока лёгкий (бот выигрывает 10 волн), графика серая, звука нет. Это не оцениваем.
